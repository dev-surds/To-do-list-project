Ultimate To-Do List

A modern, interactive To-Do List web application built with HTML, CSS, and JavaScript.
It helps users manage tasks efficiently with priority-based organization, theme switching, and an intuitive interface.

Overview

This project is designed to demonstrate frontend development skills including DOM manipulation, UI state management, and dynamic styling.
Tasks are visually organized based on priority levels, improving usability and task tracking.

Features

Add and manage tasks,
Priority-based task labeling (Low, Medium, High),
Color-coded task system for quick visual identification,
Dark/Light theme toggle,
Task search functionality,
Task completion and deletion,
Voice input feature (currently in development )

Tech Stack

HTML,
CSS,
JavaScript (Vanilla JS),
UI Highlights,
Clean and centered layout,
Priority-based color system:
Green → Low priority,
Orange → Medium priority,
Red → High priority,
Responsive design for different screen sizes,
Theme switching (Light / Dark mode).

Project Status

This project is functional and actively improving
Voice input integration is currently incomplete and will be added in future updates.

How to Run
Clone or download the repository
Open index.html in a browser
OR use VS Code Live Server for best experience
